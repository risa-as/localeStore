# تغطية الصفحات

تم حصر 35 ملف `page.tsx`. جميع المسارات أدناه تحت `app/[locale]`؛ `[locale]` يشمل العربية والإنجليزية في المصدر. عبارة «مصدر» لا تعني اختبار واجهة تشغيلية أو جميع الحالات على الموقع المنشور.

| المسار | التغطية | الخلاصة |
|---|---|---|
| `/` | مصدر + متصفح حاسوب وهاتف | بانر كبير، كتالوج بالأحدث، ووعود شحن ودفع تحتاج مطابقة السياسة |
| `/search` | مصدر + متصفح هاتف | لا إضافة مباشرة، تقييمات صفر، غياب ترقيم الواجهة وخلل مسح بحث |
| `/product/[slug]` | مصدر + عينة فعلية على الهاتف | زر شراء متأخر، وصف طويل، لا مكملات ولا اختيار لون بالسلة |
| `/landing/[slug]` | مصدر + عينة عامة على الهاتف؛ فحص ربط القالب السينمائي بالمصدر | منعزل عن المتجر، هوية عامة مختلفة، السعر الإجمالي لا يتغير أمام الزبون |
| `/cart` | مصدر ومكونات وإجراء | سعر خطي لا يطبق العروض، ملخص لا يظهر التوصيل والإجمالي الكامل |
| `/place-order` | مصدر + محاولة تنقل محلية | يدعم الزائر بالنموذج لكن إعداد الحماية يمنعه؛ عنوان 3000 المحلي يختلف عن خادم 3001، لم يثبت مسار النشر |
| `/order/[id]` | مصدر ومكونات | غياب تحقق ملكية الطلب، عرض الحالة من علامات منفصلة |
| `/order-completed/[id]` | مصدر | ملخص محدود ونص إنجليزي؛ لا يتحقق من وجود الطلب |
| `/thank-you` | مصدر ومراجعة إجراء البيانات | تحويل 12 ثانية بدلاً من إضافة مكمل مباشرة؛ قياس Purchase عند العرض |
| `/privacy-policy` | مصدر عربي وإنجليزي | النص لا يشرح بوضوح التتبع الإعلاني الموجود؛ ملاحظة اتساق محتوى لا حكم قانوني |
| `/terms-of-service` | مصدر عربي وإنجليزي | لا تفاصيل تضبط وعود الإرجاع والضمان في الواجهات |
| `/sign-in` | مصدر وإجراءات | بريد وكلمة مرور؛ لا مسار استعادة ظاهر |
| `/sign-up` | مصدر وإجراءات | إنشاء حساب تقليدي؛ ليس ضرورياً لشراء COD |
| `/unauthorized` | مصدر | شاشة بسيطة للمنع؛ لا تكفي لحماية الإجراءات |
| `/user/orders` | مصدر + بيانات مجمعة | يعتمد isPaid/isDelivered غير المتزامنين مع completed |
| `/user/profile` | مصدر وإجراء | تعديل الاسم فقط؛ إجراءات الملف تحتاج تحقق هوية صريح |
| `/admin/overview` | مصدر + تتبع الحساب | صافي الربح والإيراد غير مطابقين لتعريف صفحة الأرباح |
| `/admin/orders` | مصدر ومكونات وإجراءات + بيانات | طرق تغيير حالة متباينة، نموذج إجمالي مختلف، فشل واتساب غير واضح |
| `/admin/products` | مصدر + بيانات المخزون | قيمة المخزون بالتكلفة الأساسية تختلف عن قيمة الدفعات؛ حذف يؤثر على التاريخ |
| `/admin/products/create` | مصدر وإجراء | إنشاء دفعة افتتاحية جيد؛ حماية الإجراء ناقصة |
| `/admin/products/[id]` | مصدر وإجراء | كمية المخزون مقصورة على الدفعات جيد؛ حماية الإجراء ناقصة |
| `/admin/batches` | مصدر وإجراء ومحرك + تجربة معزولة | FIFO يعيد تخصيص كلفة الماضي؛ لا سجل تخصيص تاريخي ثابت |
| `/admin/profit` | مصدر وإجراءات ومكون حساب + تجارب | عيوب تاريخ المصاريف، كلفة الراجع والتسوية وتوزيع ربح الأصناف |
| `/admin/expenses` | مصدر وإجراءات + بيانات | قواعد التواريخ والصلاحيات والاستبدال تحتاج إصلاحاً |
| `/admin/categories` | مصدر وإجراء | حذف التصنيف لا ينظف مصفوفات المنتجات |
| `/admin/categories/create` | مصدر وإجراء | لا تحديث أسماء تصنيفات موجود؛ حماية ناقصة |
| `/admin/chats` | مصدر وإجراء وwebhook + بيانات | لا أسباب رفض منظمة؛ حدود 100 محادثة و500 رسالة |
| `/admin/marketing` | مصدر الصفحة ومسارات الإجراءات وصلاحياتها | تكامل نشر وإعلانات موجود؛ لا حاجة لإعادة بنائه، يحتاج ربط الربح المسلم |
| `/admin/modon-stats` | مصدر وإجراء ومحوّل المزود | نسبة الراجع تستثني returnReceived، ونسبة التسليم تستثني completedAccountant |
| `/admin/deal-settings` | مصدر وإجراء وربط الرئيسية | إعداد صفقة موجود؛ ليس نظام توصيات مكملة |
| `/admin/shipping-settings` | مصدر وإجراء + بيانات | القيم الحالية 4/5 مناسبة للألف، الافتراضيات 4000/5000 غير متسقة |
| `/admin/site-settings` | مصدر وإجراء | إعداد الشعار فقط؛ الهوية والنصوص والأرقام موزعة في ملفات أخرى |
| `/admin/users` | مصدر وإجراء ومخطط علاقات | حذف مستخدم يمكن أن يحذف طلباته التاريخية |
| `/admin/users/create` | مصدر وإجراء | دور المستخدم يؤخذ من المدخل دون تحقق مدير داخل الإجراء |
| `/admin/users/[id]` | مصدر وإجراء | تعديل الدور غير محمي داخلياً، وجلب سجل المستخدم كاملاً |

جرت أيضاً مراجعة middleware/auth، مخطط Prisma، التسعير والدمج وFIFO، مزودي التوصيل، webhook واتساب، نقاط API ذات الصلة، وجدولة Vercel. لم تُنفّذ عمليات إرسال أو حذف أو تغيير أدوار كتجربة على بيانات حقيقية.
